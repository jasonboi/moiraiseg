# Adopt MoiraiSeg project identity

The project name is MoiraiSeg. Public entry points are `moiraiseg.py`, `moiraiseg_gui.py`, and `MoiraiSeg启动器.cmd`.

Project metadata is stored under `.moiraiseg/` and identifies the tool as `moiraiseg`. Service environment variables, HTTP headers, browser storage keys, scripts, documentation, and user-facing text use the same identity.

The project does not retain aliases or migrations for identifiers used before this decision.
